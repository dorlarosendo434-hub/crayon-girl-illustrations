# 两头身蜡笔女孩 IP 正文配图

## 核心定位

为中文内容设计和生成两种画幅的蜡笔女孩配图：16:9 横版用于公众号、博客和正文段落；3:4 竖版用于小红书、小绿书等内容平台。目标不是做商业海报、PPT 信息图或儿童绘本，而是把文章里的关键判断、流程、结构、状态或隐喻，变成温暖、清爽、有创意、可读但不说明书的蜡笔手绘解释图。

每个用户首次使用时建立自己的专属 IP。内置蜡笔女孩只是风格、两头身比例和手绘材质的基准，不是新用户默认继承的长相和穿搭。用户 IP 的脸型、发型、服装、配饰和标志性特征是身份锚点；内置形象的浅色纸面、温暖蜡笔颗粒、严格两头身和短圆肢体是风格锚点。专属 IP 必须参与画面的核心动作，不能只是装饰。

## 首次使用必做：初始化专属 IP

在任何配图分析或生成前，检查 `assets/ip-reference/user/active-ip.png` 和 `references/user-ip-profile.md`。两者都存在才视为已完成初始化。

- 未初始化时，简短告知用户这套 Skill 会先建立专属 IP，请上传 1-3 张能看清脸、发型和标志性穿搭的形象图；正面全身图最佳，真人照片、头像、卡通或其他画风均可。没有图时也可提供清晰的外形描述。
- 用户尚未提供形象时应暂停生成正文配图，不得默默使用内置女孩代替。只有用户明确说“先用内置形象”时，才可把 05 参考图设为临时活动 IP。
- 收到形象后，必须读取 `references/ip-onboarding.md` 完成风格判断、必要的自动转绘、身份锚点提取和文件保存。
- 用户之后说“换 IP”“更换形象”或提供新形象要求替换时，重新执行同一流程，并明确替换活动 IP。

## 画幅选择

- 用户明确说“小红书”“小绿书”“竖图”或“3:4”时，生成严格 3:4 竖版。
- 用户明确指定其他比例时，优先遵守用户比例，并按竖版或横版的相近构图原则调整。
- 未指定画幅时，默认生成 16:9 横版正文配图。
- 不要把横向流程硬塞进竖图。3:4 优先使用上下阅读路径、单一主物件、角色状态或 2-4 格纵向分镜；顶部约 15% 保持安静留白，方便平台封面标题后期叠加。

## 内容角色选择

- 用户说“封面”“首图”“小红书封面”或一组图的第一张时，使用封面模式；其他图片默认使用正文/轮播内页模式。
- 封面模式不是留白版正文图：必须有一条醒目的大字主标题、一句短内容总结，以及女孩与标题或核心物件发生直接互动，例如托住、拉动、盖章、圈出或递交。
- 封面标题控制在 8-16 个字，最多两行；内容总结控制在 12-24 个字。标题是第一视觉层级，女孩和主物件共同构成第二层级，内容总结作为第三层级。
- 正文/轮播内页继续使用安静顶部留白和少量短标注；不要把封面的大标题规则套到每一张内页。

## 工作流

### 0. 选择配色

读取 `references/palette-system.md`。用户指定配色时严格使用；未指定时默认“经典绿”；用户允许自动选择时，按内容气质选择最合适的一套。一组连续配图默认保持同一套配色。

配色只作用于背景、场景物件、路径、纸片和批注。用户 IP 的固定发色、服装主色、标志性配饰和其他身份锚点不随主题色改变。无论选择哪套，整张图都必须是浅色背景，禁止大面积深色底。

### 1. 消化正文

提炼核心观点、认知转折、适合用图解释的段落和不需要配图的内容。不要平均配图，优先选择核心判断、断点、闭环、分流、对比、承接路径、常见坑和角色状态变化。

如果用户要向新手解释“某个东西是什么、如何工作、包含什么、能否复用或修改”，不要只画四个孤立图标。先提炼：

- 一句话定义
- 内部包含的 3-5 个关键部分
- 输入、处理、输出关系
- 用户最关心的复用、修改或使用方式

把这些内容组织成同一个物理场景，让读者看到它如何运转。

### 2. 先出配图策略

如果用户只要求分析配图，先给 shot list。每张图写清楚：放置段落、主题、核心意思、结构类型、女孩动作、建议元素和短中文标注。默认 4-8 张，短文 1-3 张。

### 3. 单张生成

用户明确要求生成时，直接用 `image_gen` 每张单独生成。每张只讲一个核心结构。提示词必须包含：

- 已选择的画幅：默认 16:9 横版；小红书、小绿书默认严格 3:4 竖版
- 已选择色板的浅底色；浅色背景与留白至少覆盖画面 70%
- 温暖彩色蜡笔手绘和大量留白
- 少量使用所选色板功能色的中文手写批注
- 严格两头身、大头大脸、紧凑躯干和短而圆润的胖乎四肢
- 从 `references/user-ip-profile.md` 复制当前用户 IP 的脸型、发型、服装、配饰和标志性特征，不得混入内置女孩的身份特征
- 当前用户 IP 作为核心动作主体
- 禁止 PPT、商业插画、幼稚儿童绘本、复杂架构和左上角类型标题

解释型配图可以围绕同一个问题展示“定义 + 组成 + 运行方式 + 关键能力”，但必须有清晰主次和一条主要阅读路径。不要把几个抽象图标并排后就当作解释完成。

3:4 正文/轮播内页把信息从上到下组织：顶部安静留白，中部放一个主物件或核心状态，下部让女孩完成关键动作；不要复制横图的左右长箭头、双栏对比或过宽路线。封面模式则用大标题占据上半部，女孩必须和标题或核心物件互动，不能只站在旁边。

### 4. 强制形象一致性校验

每张生成后必须读取 `references/qa-checklist.md`，并对照 `assets/ip-reference/user/active-ip.png` 和 `references/user-ip-profile.md` 逐项检查：

- 头脸大小、两头身比例、紧凑躯干和胖乎四肢一致
- 脸型、眼睛、发型、发色和气质与活动 IP 一致
- 服装、鞋履、头饰、眼镜、首饰、包类等身份锚点一致；用户没有的特征不得凭空添加
- 角色固定色、蜡笔颗粒和整体气质一致
- 色板名称、浅底色和功能色使用符合 `references/palette-system.md`

任何一项明显漂移，都不能直接交付。优先局部编辑；涉及脸、头身、发型或整体服装时重生成。不要把“同一画风”误判为“同一角色”，也不要把内置女孩的身份特征误当成必须复制的风格。

### 5. 保存交付

最终图保存到：

```text
assets/<article-slug>-illustrations/
```

按顺序命名，保留原始生成文件，不覆盖已有资产，除非用户明确要求替换。

## 输出口径

生成后报告生成数量、每张用途、保存路径，以及一致性校验结果。不要长篇解释风格理论。
