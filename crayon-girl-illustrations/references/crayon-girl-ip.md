# 用户专属两头身蜡笔 IP

## 角色定义

当前用户 IP 是正文配图的固定视觉角色。默认每张图都要出现，并承担核心动作。它不是头像贴纸或角落装饰。

正式生成前必须已完成 `references/ip-onboarding.md` 的初始化，并存在两个文件：

1. `assets/ip-reference/user/active-ip.png`：当前用户的最高优先级身份参考。
2. `references/user-ip-profile.md`：当前用户的文字身份锚点。

`assets/ip-reference/05-canonical-beret-plump-limbs.png` 仅用于判断风格、比例和材质。它不是用户身份参考，也不得覆盖用户 IP。

## 固定风格锚点

- 严格两头身：总高约为两个头高，头部约占整体高度一半，下巴到鞋底约为一个头高。
- 头和脸适当放大，形成清楚、稳定的圆润轮廓。
- 身体短小紧凑，躯干明显缩短。四肢短而圆润胖乎，手掌小而肉乎，脚踝紧凑。
- 保持成年内容创作者或工具使用者气质，不做婴儿身体、幼儿神态或甜腻卖萌。
- 使用温暖的彩色蜡笔纸面质感、可见手绘颗粒和柔和深蓝或深色轮廓。

## 用户身份锚点

每次生成前读取 `references/user-ip-profile.md`，原样保留其中记录的：

- 脸型、眼睛特征、表情气质和肤色。
- 发型、发量、发长、刘海、发色和标志性前发轮廓。
- 服装的版型、长度、主色、图案和鞋履。
- 帽子、眼镜、耳饰、首饰、包类或其他标志性配饰。
- 足以让用户一眼认出的其他特征。

主题配色只改变背景、场景物件、路径、纸片和批注，不改变用户 IP 的固定发色、服装主色和识别配饰。

## 身份隔离

内置女孩的黑长发、暖棕贝雷帽、珍珠耳钉、奶油短上衣、棕色格纹短裙、迷你斜挎包和小皮鞋都是她的身份，不是这套 Skill 的通用风格。用户 IP 没有的特征不得凭空添加。

如果用户明确选择“先用内置形象”，才按 05 参考图完整继承上述特征，并在 `references/user-ip-profile.md` 标记这是临时内置 IP。

## 性格和动作

- 温和但不软弱，好奇、认真，愿意动手整理复杂信息。
- 有内容创作者、AI 工具使用者和小工具制作者气质。
- 轻盈幽默，但不婴儿化。

常见动作包括整理纸片、理线、装入小包、标记下一步、圈重点、收纳信息、推动小机器、牵引路径、修补连接、提示风险、搬运和分拣。坐下、弯腰、行走或工作时也不能恢复常规成人比例。

## 禁止

- 不要画成 2.5 头身、3 头身或常规成人比例。
- 不要拉长躯干和腿，也不要把四肢画成细棍。
- 不要改变活动 IP 的脸、发型、发色、服装主色和配饰。
- 不要把内置女孩的帽子、发型、穿搭或配饰混入用户 IP。
- 不要变成真人照片、3D 娃娃、日漫厚涂、商业潮玩或幼儿绘本角色。

## 一致性判断

每张图都必须同时对照活动 IP 和文字档案。脸、头身、发型、服装、配饰、固定色和蜡笔质感均属于一致性范围。任何一项明显变化都视为角色漂移，必须编辑或重生成。
